# Abdul Ameen - Personal Portfolio Website

## 📌 Project Description
This is a personal portfolio website developed using HTML and CSS. It showcases my personal information, educational qualifications, technical skills, hobbies, projects, achievements, resume, and contact details.

The website has a modern design with attractive colors, animations, and a responsive layout.

## 👨‍💻 About Me
- **Name:** Abdul Ameen
- **Department:** Computer Science Engineering (CSE)
- **College:** NRI Institute of Technology
- **Location:** Andhra Pradesh, India

## 🚀 Features
- Home section with personal introduction
- Educational qualifications
- Technical skills
- Personal hobbies
- Project details
- Achievements
- Resume download option
- Contact information
- Smooth scrolling navigation
- Hover effects and animations
- Responsive design for mobile devices
