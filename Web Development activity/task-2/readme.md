# ABC College Website

## 📌 Project Description
ABC College Website is a responsive college website developed using HTML5 and CSS3. It provides information about the college, departments, courses, faculty, admissions, campus facilities, events, and contact details.

## 🚀 Features
- Home page with welcome banner.
- About Our College section.
- Departments information.
- Courses offered.
- Faculty details.
- Admission procedures.
- Campus facilities.
- College events.
- Contact information.
- Responsive design.
- Attractive colors and animations.
- Hover effects and smooth navigation.

## 🛠️ Technologies Used
- HTML5
- CSS3
