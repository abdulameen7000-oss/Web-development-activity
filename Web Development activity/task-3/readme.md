# 🛒 ElectroMart – Online Electronics Store

## 📌 Project Description
ElectroMart is a simple and attractive electronics shopping website developed using HTML5 and CSS3. It displays different electronic products such as laptops, smartphones, headphones, smartwatches, wireless keyboards, and smart speakers.

The website includes product details, prices, discounts, product comparison, services, and contact information.

## 🚀 Features
- Attractive homepage with a colorful banner.
- Electronics product catalog.
- Product prices and discount labels.
- Product specifications.
- Product comparison table.
- Fast delivery information.
- Secure payment information.
- Product warranty details.
- Contact information.
- Responsive design for mobile devices.
- Hover effects and colorful styling.

## 🛠️ Technologies Used
- HTML5
- CSS3
